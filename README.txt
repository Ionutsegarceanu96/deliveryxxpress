DeliveryXXpress — GitHub Pages Ready

IMPORTANT:
This package uses a self-contained index.html file. The CSS and JavaScript are
embedded inside index.html, so you do not need separate styles.css or script.js
files. This avoids the missing-stylesheet issue shown in the browser screenshot.

HOW TO PUBLISH:
1. Extract this ZIP on your computer.
2. Open your GitHub repository: DeliveryXXpress.
3. Click Code, then Add file > Upload files.
4. Upload index.html (and optionally this README.txt) directly to the repository
   root. Do not upload the ZIP itself and do not put index.html inside a nested
   folder.
5. Click Commit changes.
6. Go to Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose branch main and folder /(root), then Save.
9. Wait a few minutes and open:
   https://pankajwriter.github.io/DeliveryXXpress/

DEMO LIMITATIONS:
This is a coursework prototype. Booking and signup forms only validate in the
browser and do not send or store data. Parcel tracking is a fixed demo, and
dashboard figures are illustrative, not live analytics.
